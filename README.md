Задание 3. Автотесты для UI — Stellar Burgers
1. Реализация Page Object
Для организации тестов и разделения логики страниц от самих тестовых сценариев использован паттерн Page Object.
Созданы базовые и целевые классы страниц (pages/), содержащие локаторы веб-элементов и методы взаимодействия с ними:

BasePage: базовый класс с общими методами ожидания элементов, кликов и получения текста.

MainPage: описывает главную страницу сайта (кнопки «Конструктор», «Лента заказов», клики по ингредиентам, открытие и закрытие модального окна деталей ингредиента, счетчики добавления ингредиентов).

FeedPage: описывает страницу «Лента заказов» (счетчики «Выполнено за всё время», «Выполнено за сегодня», блок заказов «В работе»).

2. Кросс-браузерное тестирование и Allure-отчёты
Тесты успешно реализованы с использованием фреймворка pytest и библиотеки allure-pytest для генерации детализированных отчётов. Настроено автоматическое создание артефактов и кросс-браузерный запуск в Google Chrome и Mozilla Firefox.

3. Проверка основной функциональности
Переход по клику на «Конструктор»:
Проверен корректный переход со страницы ленты заказов или личного кабинета обратно в основной конструктор бургеров по клику на соответствующую кнопку.

Переход по клику на раздел «Лента заказов»:
Проверен успешный переход на страницу общей ленты заказов из шапки сайта.

Всплывающее окно с деталями ингредиента:
При клике на любой ингредиент в конструкторе открывается модальное окно с детальной информацией о выбранном компоненте.

Закрытие всплывающего окна:
Модальное окно успешно закрывается кликом по иконке крестика («X»).

Увеличение счётчика ингредиента:
При перетаскивании или добавлении ингредиента в заказ счётчик конкретного ингредиента корректно увеличивается.

4. Тестирование раздела «Лента заказов»
Счётчик «Выполнено за всё время»:
После успешного оформления нового заказа значение глобального счётчика общего количества выполненных заказов увеличивается.

Счётчик «Выполнено за сегодня»:
После создания заказа значение суточного счётчика выполненных заказов увеличивается.

Отображение заказа в разделе «В работе»:
Сразу после оформления заказа его уникальный номер появляется в блоке заказов со статусом «В работе».
